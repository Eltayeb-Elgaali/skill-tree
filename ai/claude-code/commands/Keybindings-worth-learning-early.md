### The console is a terminal program, so a few keystrokes do more than any slash command:

- Esc interrupts the agent mid-task. The turn stops, nothing else is lost, and you can redirect it with a new prompt.
- Esc pressed twice opens the option to jump back to an earlier message and edit it, which reruns the conversation from that point.
- Up recalls previous prompts, the same way shell history works.
- Shift+Tab cycles the permission mode of the session (normal, auto-accept edits, plan mode). You met these modes in hour 006.
- Ctrl+C twice exits the console.
