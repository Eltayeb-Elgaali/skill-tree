## When to Use `/clear` vs `/compact`

| Situation | Command |
|-----------|---------|
| Finished a task, moving to something unrelated | `/clear` |
| Same task, but context feels full or is drifting | `/compact` |
| Starting your day on a fresh problem | `/clear` |
| Long refactor, want to trim noise but keep the plan | `/compact` |

```bash
/compact keep the failing test names and the list of files already edited.
```
