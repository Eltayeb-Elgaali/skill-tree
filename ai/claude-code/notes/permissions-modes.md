| Mode | Behavior | Use it when |
| --- | --- | --- |
| `default` | Prompts when an action needs approval | Normal work, unfamiliar code |
| `acceptEdits` | Automatically accepts file edits; other actions follow applicable permissions | You trust the edits and want fewer prompts |
| `plan` | Explores and plans without implementing changes | You want a plan or a review first |
| `bypassPermissions` | Bypasses permission checks; use only in isolated environments | Rarely, and only somewhere you can throw away |
